# 🔲 QR Code Generator

Стильное десктопное приложение для быстрой генерации QR-кодов, написанное на **Python** с использованием библиотеки **CustomTkinter**.

---

## ✨ Особенности

- 🎨 **Современный UI:** Использование CustomTkinter для стильного тёмного/светлого интерфейса.
- 🔗 **Умная обработка ссылок:** Автоматически подставляет `https://`, если ты ввёл адрес без протокола.
- 🖼 **Мгновенный просмотр:** Сгенерированный QR-код сразу открывается на экране.
- 🧹 **Авто-чистка:** Удаление лишних пробелов из введенной строки.

---

## 🛠 Технологии

- **Python 3.x**
- **CustomTkinter** (Современный графический интерфейс)
- **qrcode** (Генерация QR-кодов)
- **Pillow (PIL)** (Работа с изображениями)
